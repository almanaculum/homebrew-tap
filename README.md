# Almanaculum Homebrew tap

This tap packages the Luff Rust CLI for Homebrew. When the tap is published,
install it with:

```sh
brew install almanaculum/tap/luff
luff --help
```

Run `luff map --no-counts` in a project to list its files. The formula builds
the CLI from the official Luff release source.
[Luff releases](https://pypi.org/project/luff/#history)
